# 早押しステージ（hayaoshi-stage）

一人称視点の早押しクイズゲームの試作版です。ブラウザだけで動きます。

## 遊び方
1. サーバーにのせて `index.html` を開く（models フォルダの読み込みが必要）（スマホ・タブレットは横向き）
2. 「タップして入場」を押す
3. 問題が出たら、画面をタップ（PCはスペースキー）で早押し
4. 下に出る4つの文字から、答えの次の1文字を選ぶ

## いまできること（段階1）
- 会場・ステージ・観客・司会者・4人の出場者
- 机・モニター・早押しボタン
- 自分の手がボタンを押す動き
- コンピューター相手の5問勝負
- 人（出場者・司会者・観客・自分の手）は Microsoft Rocketbox の3Dモデル（MITライセンス、models/LICENSE-Rocketbox.txt）
